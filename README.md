 # Web Development Assignment

## About the Project
This repository contains my Web Development practical assignments. It covers Terminal commands, Git, GitHub, HTML, CSS, Flexbox, and CSS Grid.

The main goal is to learn the basics of web development and understand how to create responsive and well-structured web pages.


## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Terminal

## Learning Outcomes

- Understanding basic terminal commands.
- Managing projects using Git and GitHub.
- Creating structured web pages using semantic HTML.
- Styling web pages using CSS.
- Understanding CSS positioning.
- Creating responsive layouts using Flexbox.
- Building layouts using CSS Grid.
